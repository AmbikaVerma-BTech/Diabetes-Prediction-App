# 🩺 Diabetes Prediction System

A machine learning web application that predicts whether a person is diabetic or not based on medical parameters using **Support Vector Machine (SVM)**.

### 🔗 Live Demo
👉 [Click here to try the app](https://diabetes-prediction-app-foryou.streamlit.app)

---

## 📌 Project Overview

This project uses the **PIMA Indians Diabetes Dataset** to train a Support Vector Machine (SVM) classifier.  
The model takes 8 medical features as input and predicts the likelihood of diabetes.

### Features used:
- Pregnancies
- Glucose
- Blood Pressure
- Skin Thickness
- Insulin
- BMI
- Diabetes Pedigree Function
- Age

---

## 🛠️ Tech Stack

- **Python**
- **Scikit-learn** (SVM + StandardScaler)
- **Streamlit** (Web App)
- **Joblib** (Model saving)
- **NumPy & Pandas**

---

## 📊 Model Performance

- Training Accuracy: ≈ **78.7%**
- Test Accuracy: ≈ **77.3%**
